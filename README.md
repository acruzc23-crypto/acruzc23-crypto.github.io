## ✨ Características

- Diseño responsive (se adapta a celular, tablet y computadora)
- Modo claro / oscuro (recuerda tu preferencia)
- Proyectos generados dinámicamente con JavaScript y filtros por tecnología

- Sin frameworks: HTML, CSS y JavaScript puro

## 🚀 Ejecutar localmente


## ➕ Agregar un proyecto

En `script.js`, añade un objeto a la lista `projects`:

```js
{
  icon: "🚀",
  title: "Mi proyecto",
  description: "Qué hace el proyecto.",
  tags: ["python"],          // o "javascript"
  stack: "Python · Flask",
  repo: "https://github.com/acruzc23-crypto/mi-proyecto",
}
```
